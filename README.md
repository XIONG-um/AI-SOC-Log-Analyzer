# AI-SOC-Log-Analyzer
# 🤖 AI 安全日志分析工作台 (AI-Powered SOC Log Analyzer)

> 基于 Python + Streamlit + 大语言模型（LLM）构建的轻量级蓝队安全运营辅助工具。
> 旨在解决安全运营中心（SOC）中“日志量过大、告警疲劳”的痛点。

## 📌 项目背景
在日常蓝队安全运营中，每天面临海量的 Web 访问日志、Linux 系统日志。传统人工分析耗时耗力，且容易遗漏关键攻击行为。本项目利用大语言模型（LLM）的语义理解能力，对日志进行智能降噪、攻击特征提取和自动化分类，显著提升安全分析效率。

## ✨ 核心功能
*   **自动告警降噪**：自动区分【高危攻击】、【待人工复核】和【正常业务误报】（如：识别出运维正常备份、SSO单点登录、代码本身的Notice报错）。
*   **攻击源提取**：快速提取恶意 IP、攻击 Payload 特征。
*   **智能研判报告**：一键生成包含“处置建议”和“溯源方向”的标准安全研判报告。
*   **人机协同闭环**：支持人工二次验证，防止 AI 幻觉造成的误判。

## 🛠️ 技术栈
*   **开发语言**：Python 3.x
*   **前端框架**：Streamlit
*   **大模型接口**：Google AI Studio (Gemini API)
*   **网络请求**：Requests
